## The scene

A team buys every engineer an agent subscription. Three weeks later the dashboard shows twice as many pull requests opened and the same number shipped. The extra ones are sitting in review, getting older.

## The play

Before you spend anything, walk the line and find where work waits longest. Spend there. Then look again a week later, because it will have moved. That loop is the whole method, and it has no last step.

## Smells

- A big budget for coding agents while pull requests wait two days for a reviewer.
- Dashboards that count tokens, lines of code and pull requests opened, and say nothing about queues.
- Nobody can say how long a change sits at each station.
- A transformation project with a finish line.

## First move

Put one number on each station this week: how many items are waiting, and for how long. The biggest number is your roadmap.

## In Lights Out

Install something away from the constraint and ten days later the log tells you the needle did not move. The price lands in early spend. Seven signals with traffic lights show where the pile went next.
